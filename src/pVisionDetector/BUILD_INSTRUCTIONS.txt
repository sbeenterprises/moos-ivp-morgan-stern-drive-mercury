===========================================
pVisionDetector - Build Instructions
===========================================

1. BUILD THE APPLICATION
-------------------------
cd ~/Documents/automation/moos-ivp-morgan-stern-drive-mercury/
cd build/
cmake ../
make
sudo make install

2. TEST THE APPLICATION
-----------------------
# Terminal 1: Start MOOSDB
cd ~/Documents/automation/moos-ivp-morgan-stern-drive-mercury/missions/
MOOSDB pVisionDetector.moos

# Terminal 2: Start pVisionDetector
pVisionDetector pVisionDetector.moos

# Terminal 3: Monitor with uXMS
uXMS pVisionDetector.moos
# Type: pVisionDetector
# (View AppCast)

# Terminal 4: Monitor VISION_REPORT
uMS pVisionDetector.moos
# Type: VISION_REPORT
# (Watch detections)

3. TROUBLESHOOTING
------------------
If compilation fails:

a) Check OpenVINO:
   ls /usr/lib/libopenvino.so
   
b) Check OpenCV:
   pkg-config --modversion opencv4
   
c) Check MOOS:
   which pAntler

d) Check model exists:
   ls /home/douglas/Documents/yolo/yolo11n_openvino_model/

4. INTEGRATION WITH pSensorFusion
----------------------------------
Once pVisionDetector works, integrate with pSensorFusion:

ProcessConfig = pSensorFusion
{
  AppTick   = 10
  CommsTick = 10
  
  // ... other config ...
}

ProcessConfig = pVisionDetector
{
  AppTick   = 20
  CommsTick = 20
  
  rtsp_url = rtsp://...
  yolo_model_path = /path/to/model
  // ... other config ...
}

Both apps will publish to MOOSDB:
- pVisionDetector → VISION_REPORT
- pSensorFusion → NODE_REPORT (fused)
